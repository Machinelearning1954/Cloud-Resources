# ADR 0014 — AI-Leak Forensics Checklist

**Status:** RECONSTRUCTED (core contract preserved) · **Rebuilt:** 2026-11-10

## Decision

Any intake claiming to be a GTA 6 "leak" or AI-adjacent media is processed through a
fixed forensic checklist **before** it can influence any decision:

1. Provenance — who uploaded, when, to where; is there a first-hand source?
2. Artifact trail — hands, text signage, symmetry, physics continuity, repeated faces.
3. Cross-reference — does an official R* channel corroborate? (No corroboration → GOSSIP.)
4. Motive fit — who profits from this being believed?
5. Ledger entry — the row is written regardless of outcome.

## Origin

Row 0014: AI-generated "leak" media with artifact trails. The checklist exists so each
forgery incident makes the machine stronger, not angrier.

## Consequences

- Unverifiable media can never adopt into architecture; only verified official uploads
  (Row 60 evidence chain) may become REFERENCE evidence.
