API Usage

You can also get predictions by sending a POST request to the /predict endpoint with JSON data:


curl -X POST -H "Content-Type: application/json" \
-d 	"{\"sepal_length\": 5.1, \"sepal_width\": 3.5, \"petal_length\": 1.4, \"petal_width\": 0.2}" \
http://<your-app-url>/predict

Or a GET request to /health to check service status.
